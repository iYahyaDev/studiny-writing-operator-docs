# Studiny Writing Operator — Support

This Integration is operated privately by the authorized Studiny owner. Student support is handled through the separate Studiny service.

For authorized Integration support, email **contact@studiny.online**. Include the time, the operation you were attempting, and a short description of the issue. Keep API tokens, private keys, OAuth codes, passwords, and student data out of the message and any attachments. For suspected credential exposure, contact the owner promptly so the installation can be reviewed and access revoked.
